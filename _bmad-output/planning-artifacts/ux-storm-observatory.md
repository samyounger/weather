# Storm story UX contract
Use existing warm paper/navy palette, generous mobile spacing and compact story labels. Landing view is the historical storm story; a clear button opens existing trend explorer and a second returns to story.
Order: historical-case label + name + one-paragraph narrative; local story metric cards and coverage; lifecycle schematic + sourced timeline; local hourly replay with accessible table; local threshold investigation; seasonal reference; historical warning context and forecast-vs-outcome evidence; methodology/source drawer.
Always show historical dates; no active alert styling implying a live service. Distinguish national report figures from local station cards. Error/loading/empty/comparison-unavailable states retain the public story and source links. Retry affects private observations only.
Heading hierarchy, visible focus, buttons with aria-pressed navigation, labelled controls, no colour-only meaning. Source links identify publisher and publication/retrieval dates. No map tiles or external fonts. At 375px no horizontal page overflow; tables may scroll within labelled containers. Reduced-motion preference disables decorative animations.
