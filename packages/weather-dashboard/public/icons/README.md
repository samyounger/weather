# Weather app icons

Generated using the built-in image-generation tool. The 1024px source is retained as `weather-source-1024.png`; distribution icons are opaque RGB PNGs resized with Lanczos resampling. The maskable variant adds padding to keep the primary artwork inside the central safe zone.

Prompt: Square full-bleed opaque deep navy (#16324f) weather app icon; centered bold white cloud, warm golden sun and three cyan rain strokes; subtle rolling hills; simple crisp vector-like graphic with restrained dimensionality; legible at 60px; no text, frame, rounded outer corners or mockup.

## iOS installation

Open the deployed app in Safari, select Share → Add to Home Screen, and enable Open as Web App if offered. Existing saved icons may need to be removed and added again because iOS caches their artwork.
